# Changelog FogMap

Формат: `MAJOR.MINOR.PATCH` (база — файл `version`, полная сборка —
`<base>.<count>-g<sha>` из git). Правила бампа: `docs/versioning.md`.

## [1.4.0] — 2026-09-22 (MINOR)

Надёжный эко-режим: GPS будит всегда (change `fog-eco-reliability`, код; полевая приёмка открыта):
- STANDBY переведён с BALANCED 90с/150м на HIGH 60с/30с/0м; вето сна после холостого BURST убрано (только метрика).
- BURST→ACTIVE по MOVING-вердикту ИЛИ скорости >5 м/с при acc≤25м; дебаунс ACTIVE→STANDBY после скорости 3 мин.
- Открыто до поля: STANDBY 30/60с, холд 3/5мин; задачи 3.2/4.1/4.2 требуют устройство.

## [1.3.0] — 2026-09-22 (MINOR)

Честные метрики импорта и счёта (change `fix-import-metrics`, код; полевая приёмка открыта):
- Импорт восстанавливает эко-метрики дня из `counters.json` выгрузки вместо пересчёта из прореженного raw; без данных — «нет данных», а не 0.
- Чанки rebuild режутся по времени (~120 с): тишина не впитывается в `time_s` дня.
- `flush()` сериализован мьютексом; дистанция батча считается от хвоста дня, хорда wake-якоря — только коридор тумана (21.09: 19.59 → ~11.4 км).

## [1.2.0] — 2026-09-21 (MINOR)

Статика доверия по времени + живая диагностика тишины (change `fix-eco-signal-loss`, код; полевая приёмка открыта):
- TrustEngine: история по времени (60 с), статичный кластер по якорю ≥ 40 с — ходьба на плотной доставке снова MOVING.
- Ворота C: `veto_stale` только для не-MOVING точек.
- `no-fix`: ветка тишины Fused оживлена, событие несёт фактический `gap_ms`.
- Метрики: префикс пробуждения отдельно от разрывов, пер-эвентные `prefix_m/src` во flush, медиана префикса по бакетам, карточка дня показывает медиану и разрывы.

## [Unreleased]

- Полевая приёмка `fix-eco-signal-loss`: прогон дня, сверка доли отброшенного движения, BURST→ACTIVE, медианы префикса (задачи 3.2, 5.1–5.3).

## [1.1.0] — 2026-09-21 (MINOR)

Накопленные фичи после 1.0.0 (бамп догоняющий, одним шагом):
- Эко-губернатор трекинга ACTIVE/STANDBY/BURST + эко-метрики и причина wake в логах.
- Эко всегда включен, тумблеры удалены.
- Wake-balance-parking: раннее пробуждение motion/WiFi, честный префикс от якоря.
- Smooth-fog-zoom: доработки FogMask/оверлея/экрана карты.
- Упрощение выходов APK: в `dist` только latest, версионированная копия в `archive/`.
