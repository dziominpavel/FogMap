### Добавлено

- **Прогресс по 13 регионам Беларуси** (change `add-region-progress`, поле 4.3 открыто):
  - Полигоны регионов из OSM (6 областных городов, 6 областей, республика; outer-only, ray casting + bbox pre-filter); хардкод в `region/Regions.kt`.
  - Materialized counters `region_<id>_cells` инкрементируются в той же транзакции, что и открытие ячеек FogRepository; точка в зоне пересечения (Минск в Минской области) попадает в оба счётчика.
  - Экран «Прогресс по регионам» из Stats: группы Города/Области/Республика, км² и производный %, сортировка по убыванию процента.
  - Unit-тесты: 25 suites зелёные (RegionGeometryTest 13/13); спека `region-progress` синкнута; change в `archive/2026-09-24-add-region-progress` (12/13, поле 4.3).
- **Система достижений** (change `add-achievements`, поле 5.3 открыто):
  - Room-таблица `achievements` (только unlocked, миграция v6→v7), определения — Kotlin-константы: 45 ачивок (13 регионов × 10/50/100%, площадь 10/100/1000 км², серия 3/7/30 дней).
  - `AchievementChecker` (чистые триггеры, unit-тесты), вызов после инкремента counters в `FogRepository.appendPoints` и в `TrackRepository.startDayChunk` (streak `streak_days`/`streak_days_best`/`streak_last_day`).
  - Экран «Достижения»: группы Регионы/Площадь/Серии, unlocked с датой, locked с условием, Toast при разблокировке; вход из Stats.
  - `docs/vision.md` — pivot зафиксирован; спека `achievements` синкнута (4 requirements); change в `archive/2026-09-24-add-achievements` (15/16, поле 5.3).
  - Тесты: BUILD SUCCESSFUL (AchievementCheckerTest 11/11).
- **Границы регионов на карте** (change `add-region-borders`, тумблер выключен по умолчанию):
  - Секция «Карта» в настройках: «Границы регионов на карте» (`region_borders`, default off), эффект мгновенный.
  - Слой `map/RegionBordersLayer.kt`: полилинии MapKit внутри MapView — физически под вуалью тумана, видны только в открытых дырках; республика — жирная сплошная, область — штриховая, город — тонкая сплошная (городские контуры скрыты ниже z10); слой живёт только на главной карте.
  - Кольца для отрисовки: только связные куски региона (вложенные дырки пропущены), незамкнутые кольца замыкаются явно.

### Исправлено

- **Честные км² и проценты** (в составе change `add-region-borders`):
  - Широтная поправка `cos²(широты)`: 0.000365 км²/клетка был экваторным номиналом, на широте Минска реальная ~0.000127 км² — все км² и проценты завышались в ~2,9 раза. Конвертация через `areaPerBaseCellKm2(lat)`: регионы — центроид полигонов, глобальные метрики — средняя широта Беларуси; счётчики хранятся в клетках, миграции нет.
  - Знаменатель процента региона — площадь полигонов, посчитанная в рантайме (шалеус по не вложенным кольцам), вместо 13 ручных констант: `gomel_oblast` был 33 469 вместо ~40 211 км² (+20,2%), город Гомель — 160,4 вместо ~144,5 км² (−9,9%).
  - Ачивка «100% региона» срабатывает при `percent >= 99`: полное открытие даёт ~98–102% из-за представительной широты, без допуска могла бы не выстрелить.
- **Протухший `trackId` после импорта/rebuild** (24.09, fix-stale-track-id): точки после импорта debug-ZIP писались с несуществующим id («сироты») — вечерние маршруты пропадали из истории при живом raw. `FogRepository.appendPoints` внутри транзакции переоткрывает строку дня и возвращает фактический id в `BatchResult(newCells, distanceM, trackId)`; `TrackingService.flushLocked` переоткрывает день при исчезновении строки (`day_chunk_recovered`, `row_missing`/`stale_id`) — покрывает импорт/rebuild и `deleteTrack` за сегодня. Спеки: `tracking`, `track-debug`, `history`. Тесты: регрессионный `appendPointsRecoversStaleTrackIdAfterRebuild` (androidTest 6/6 на AVD), unit-тесты зелёные.

## [1.5.0] — 2026-09-22 (MINOR)

Единый экранный источник позиции и видимость первого запуска (change `first-launch-visibility`, код; архивация с 4/13 задачами, полевая приёмка открыта):
- Гейт accuracy ≤ 100 м (`GeoStatus.plausible()`): фикс хуже не двигает курсор, показную дырку и камеру; `liveLatLon` = позиция слоя MapKit иначе Fused-фолбэк (ON_START/ON_STOP, `lastLocation` через гейт).
- Fallback-курсор под вуалью той же формы — только пока слой не отдал объект (на экране всегда одна точка); чип «Гео выключено» / «Ищу спутники…» / «Точка получена» / «Протухло» (120 с), follow/FAB через тот же гейт.
- Полевой фикс: живой синк снимка слоя (тик 1 с, эпсилон 2 м) — позиционные события MapKit не приходили, дырка/follow замерзали и курсор выезжал из креста; свежесть чипа от любого источника (не врёт «Протухло» при живом GPS).
- Открыто до поля: 1.3, 2.1, 2.3, 3.2, 3.3, 4.1, 4.2, 5.1, 5.2.

## [1.3.0] — 2026-09-22 (MINOR)

Честные метрики импорта и счёта (change `fix-import-metrics`, код; полевая приёмка открыта):
- Импорт восстанавливает эко-метрики дня из `counters.json` выгрузки вместо пересчёта из прореженного raw; без данных — «нет данных», а не 0.

## [1.2.0] — 2026-09-21 (MINOR)

Статика доверия по времени + живая диагностика тишины (change `fix-eco-signal-loss`, код; полевая приёмка открыта):
