# FogMap

Android-трекер с туманом войны поверх Яндекс Карты.

Идея: карта изначально покрыта туманом. По мере реальных перемещений человека
туман открывается — как в RPG (RDR2 и подобные). Никаких квестов, артефактов
и сюжета: только трекер + туман + статистика.

Статус: **сбор информации, кода нет.** Не спешим, чтобы не переделывать.

- Репозиторий: https://github.com/dziominpavel/FogMap
- Карта: Яндекс MapKit (Android)
- Методология: OpenSpec (`openspec/`), все артефакты — на русском
- Доки: `docs/`
