# Технические сложности и риски (накопитель, 2026-09-14)

Без кода. Только фиксация, что предстоит решить до/во время реализации.

## 1. Рендер тумана на MapKit

Два подхода:

- **GRID (рекомендуется на старт):** мир режется на ячейки 100–200 м
  (WebMercator / H3 / S2). Храним только ID посещенных ячеек в SQLite.
  Рисуем полигонами только видимую область (viewport culling + склейка
  прямоугольников + LRU-кэш, как в FogBound). Дешево, масштабируется.
  Минус — видна «квадратность».
- **MASK (красиво, дорого):** полноэкранный Canvas-оверлей с «дырками»
  вокруг трека (PorterDuff DST_OUT), пересчет geo→screen каждый кадр.
  Плавный RDR2-туман с градиентом, но нагрузка на CPU/GPU и лаги на пан/зум.

Решение: стартовать с GRID, MASK — только как эксперимент позже.

## 2. Фоновый трекинг

- FusedLocationProvider + ForegroundService (type=location) + уведомление.
- Разрешения ACCESS_FINE + BACKGROUND_LOCATION (запрос в два шага).
- Doze и китайские прошивки (Xiaomi/Huawei) убивают сервис — нужен онбординг
  «разреши автозапуск / отключи оптимизацию батареи».
- Интервал ~5–10 сек / 10–20 м + батчинг, иначе батарея умрет за 4 часа.
- Фильтр дрейфа: отбрасывать точки с accuracy > ~25 м, скорость > ~150 км/ч.

## 3. Рост данных

- Активный юзер за год: порядка 50–200 тыс. ячеек. Хранить ID ячеек
  с индексом, не полигоны. Рендерить только видимое.
- Импорт GPX / Google Timeline — в скоуп MVP (иначе холодный старт).
- Экспорт GPX — для доверия и переносимости.

## 4. Читы и приватность

- Mock-location (isMock) и эмуляторы: на старте без рейтингов не критично,
  проверку заложить минимальную.
- Все локально по умолчанию. Любой сервер/аналитика — отдельным решением.

## 5. Юридическое и модерация

- [ ] Оферта MapKit: перекрытие карты туманом, логотип, копирайты.
- [ ] Лимиты/тарифы MapKit, офлайн-карты (в lite может не быть).

## 6. Оценка трудоемкости (очень грубо, для ориентира)

- MVP локальный (карта + трекинг + сетка + статистика): ~3–6 недель соло.
- + импорт истории, полировка фона: +1–2 месяца.
- Сервер/синк/социальное: x2–x3. Не в скоупе, зафиксировано в vision.
