# Журнал решений

Формат: дата — решение — причина. Новое решение добавляется сверху.

## 2026-09-14 — Только трекер, без игры

Решение: никаких квестов, артефактов, сюжета, гильдий, лидербордов.
Причина: запрос владельца — «именно трекер с туманом».

## 2026-09-14 — Карта: Яндекс MapKit, только Android

Решение: Android + Яндекс MapKit, iOS вне скоупа.
Причина: качество карт/геокодера в РФ, русскоязычная аудитория.

## 2026-09-14 — Офлайн-first, все локально

Решение: туман и треки живут на телефоне (SQLite), без обязательного бэкенда.
Причина: приватность истории перемещений, работа без сети, простота MVP.

## 2026-09-14 — Туман: стартовать с GRID

Решение: сетка ячеек 100–200 м, рендер только видимой области.
Причина: масштабируемость и простота; плавная маска — позже как эксперимент.

## 2026-09-14 — Сначала доки, потом код

Решение: накапливаем vision/research/risks, код не пишем до созревания решений.
Причина: не переделывать.

## 2026-09-14 — OpenSpec обновлен 1.11.0 → 1.13.0

Решение: глобальный CLI обновлен до последней (latest на 2026-09-14 — 1.13.0).
Причина: инициализация нового проекта на актуальных шаблонах.
