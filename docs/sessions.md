### Открытый вопрос: авто-размер ячейки (2026-09-14)

Предложение владельца: размер зависит от скорости — пешком 100 м,
велосипед 200 м, авто за городом 500 м. Разобрали: переменная сетка
ломает ID/площадь/рендер. Владелец согласился на альтернативу —
фиксированная сетка 100 м + адаптивный радиус открытия по скорости.
Зафиксировано в `decisions.md` и `plan.md`. Осталось задать пороги/радиусы.

### Решения ЧП-2/ЧП-4, часть 3 (2026-09-14)

- Радиусы: 100/200/500 м по скорости. Площадь: ячейки × 0,01 км².
- Провайдер: FusedLocationProvider (хвост — без Play Services).
- Интервалы 5–10 сек / 10–20 м, фильтры стандартные.
- Статистика: полный набор (площадь/дистанция/треки/время, день/неделя/все).
- MVP: только русский, portrait, без темной карты. Аналитики нет,
  только крашлитика.

### Вопрос владельца про MapKit (2026-09-14)

Вопрос: что за Full/Lite, платно ли, есть ли API Яндекса / бесплатные альтернативы.
Проверено по докам Яндекса: MapKit — SDK Яндекса для iOS/Android;
бесплатно до 1000 DAU/сутки онлайн при открытом бесплатном приложении
(офлайн, мониторинг транспорта, платное/закрытое приложение — коммерция
от 195 000 ₽/год). На MVP платить не нужно. Осталось решить Full vs Lite
по факту нужных функций (карта+полигоны vs поиск/маршруты).

Уточнение владельца: пользователей будет до 50 максимум (с запасом).
Вывод: лимит 1000 DAU закрывает с 20-кратным запасом, вопрос тарифов снят.
Зафиксировано в `decisions.md` и `plan.md`.

### Решения часть 4 (2026-09-14)

- Импорт и экспорт — оба ПОСЛЕ MVP.
- minSdk API 26 (Android 8+), target — по требованиям Play 2026.
- История полная (список + детали + удаление + переименование).
- Офлайн-карт нет, только онлайн. Авторестарт трекинга после ребута.
- Пауза «не писать» есть, онбординг батареи есть, эко-режима нет.
- Точки пачками, статистика счетчиками, БД без шифрования.
- Туман стандартный, агрегация на мелких зумах, viewport-оптимизация сразу.
- Импорт/экспорт GPX + Timeline после MVP.
- Проект персональный, без Play Store: декларация, демо, нейминг не нужны,
  раздача через APK.
- Точки бессрочно, один app-модуль, без CI, подпись APK.
- Тесты unit + ручные, пустые состояния с подсказкой, уведомление стандартное.
- Без Play Services — заглушка, интервалы без адаптации, детали импорта/экспорта
  на этапе после MVP. Шаблон ЧП принят, отдельный ЧП архитектуры не нужен.
  Остаток перед кодом — 4 проверки: Lite/Full+версия, легальность тумана,
  targetSdk, тексты + схема таблиц в OpenSpec.
