# План реализации по чекпоинтам (каркас, 2026-09-14)

Статус документа: **каркас для обсуждения, не согласован. Ничего не решено —
ниже только вопросы, на которые надо ответить до кода.**
Цель: максимально подробно понять, КАК именно реализуем, и зафиксировать.

## Правила работы (зафиксировано)

1. Сначала доки и решения, потом код. Код не пишем, пока все чекпоинты
   не перейдут в статус «согласован».
2. Каждый чекпоинт = постановка + критерии готовности (DoD) + открытые вопросы.
3. Каждая сессия заканчивается записью в `docs/sessions.md`:
   что обсудили, что решили, что осталось открытым.
4. Любое решение, влияющее на скоуп/архитектуру, дублируется в `docs/decisions.md`.
5. Детализация через OpenSpec: на каждый крупный чекпоинт — свой change
   в `openspec/changes/`, мелкие уточнения — правками в `docs/`.

## Статусы чекпоинтов

- `черновик` — есть вопросы, не обсуждали.
- `в обсуждении` — обсуждаем прямо сейчас.
- `согласован` — постановка зафиксирована, переделывать без нового решения нельзя.
- `в реализации` — только после согласования ВСЕХ чекпоинтов.

## Шаблон описания чекпоинта (на согласовании)

1. Цель. 2. Вход/выход. 3. Постановка. 4. DoD.
5. Зависимости. 6. Риски. 7. Открытые вопросы. 8. Артефакты OpenSpec.
