# Исследование рынка (накопитель, 2026-09-14)

Вывод explore-сессии: механика «ходил — открыл туман» уже не нова.
Оригинал жанра — Fog of World (iOS, 2012). Ниже — найденное в Google Play
и на GitHub, все на Google Maps / OSM, не на Яндексе.

## Найденные аналоги

| Приложение | Платформа | Заметки |
|---|---|---|
| Fog of World (Ollix) | Android + iOS | Эталон жанра. Треки, импорт GPX/KML, синк в Dropbox/Drive, все локально |
| Fog Map (osmfogmap) | Android | Простой трекер тумана + счетчик площади |
| Walksy: Fog Map Walking Game | Android + iOS | Игровой: ранги, зоны, гильдии, лидерборды — нам НЕ образец (мы без игры) |
| FogWalker | Android | Приватность: все только на телефоне, офлайн, без аккаунта — близкий дух |
| FOG: Fog of War Walking Map (MAREN) | Android, 07.2026 | Персонаж, пути, импорт Google Timeline, разовая покупка вместо подписки |
| Breevy | Android + iOS | Сетка 100x100 м, XP, награды |
| DeFog | скоро в GP | Фишка «замкнутая петля открывает область» |
| FogBound (GitHub, open-source) | RN + Expo + SQLite + Skia | Сетка 200 м, viewport-рендеринг, LOD. Кандидат для подсматривания архитектуры |

## Выводы для нас

1. Ниша «трекер с туманом» занята, но ниша «такое же на Яндекс Картах
   для RU-аудитории» — свободна. Это наша отстройка.
2. Простота — тоже отстройка: конкуренты уходят в геймификацию,
   мы держим «только трекер».
3. Импорт истории (Timeline/GPX) есть у лучших — без него холодный старт
   убивает мотивацию. Зафиксировать как обязательное для MVP.
