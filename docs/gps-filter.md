# GPS-фильтр FogMap: полный алгоритм

Дата калибровки: 2026-09-19 (полевой разбор треков 18–19.09, Минск, машина+пешком).
Статус: корректен на сегодняшний день; дальше — по данным replay-цикла.

## 1. Конвейер точки

```
[FusedLocation ~8с / 15м]
    |
    v
[LocationFilter] -- accuracy/speed/mock --> только счетчик rejected_*
    |                                        (координаты — лишь в raw_fixes)
    v
[TrustEngine] -- STAND --> дроп из track_points (в raw пишется)
              -- SUSPECT --> пишется + счетчик jump, туман закрыт навсегда
              -- MOVING ---> пишется, туман — через ворота C
    |
    v
[track_points: time/lat/lon/acc/speed/trust/state/reject/fogOpened]
    |
    v
[PendingGate LAG=2] -- подтвердить --> открыть туман (кисть + коридор)
                    -- veto_return --> закрыто навсегда + причина в точке
                    -- veto_stale ---> закрыто навсегда + причина в точке
```

Инвариант разбора хвоста: живой батч <= 20 + перенос <= 2 <= окно 32.
Rebuild идет чанками по 20 — те же гарантии, что живой flush.

## 2. LocationFilter (ворота 0: грубая годность)

| Проверка | Порог | Исход |
|---|---|---|
| mock-провайдер | — | дроп (`mock`) |
| нет accuracy | — | дроп (`accuracy`) |
| accuracy | > 25 м или <= 0 | дроп (`accuracy`) |
| скорость чипа | > 41.67 м/с (150 км/ч) | дроп (`speed`) |

Отбросы в трек не пишутся, в туман не идут, видны только счетчиком
(`rejected_accuracy/speed/mock_day_*`) и строкой в `raw_fixes`.
Данные 19.09: accuracy 232, speed 35 (глюки чипа, не реальная скорость).

## 3. TrustEngine (ворота A/B: вердикт по последовательности)

Чистый объект без состояния: вход — предыдущее состояние + окно до 8 точек
(HISTORY_MAX), выход — вердикт (state, trust, openFog, countReject, resetHistory).
История в памяти — ВСЕ принятые точки, включая STAND (иначе холодный старт
никогда не выйдет из статики).

### 3.1. Порядок проверок (первое сработавшее решает)

```
1. Возврат в якорь после SUSPECT?
   out = dist(якорь, подозрительная), back = dist(якорь, новая)
   out > 1м И back < 0.5 * out --> STAND trust=70 (выброс подтвержден)
2. Статичный кластер?
   точек с новой >= 5 И dist(старейшая окна, новая) <= 25м
   --> STAND trust=80 (заморозка открытия, НЕ отброс)
2б. Телепорт-гейт: сдвиг > 500м между соседними доставками?
   dt намеренно не участвует (кейс «аэропорт через тишину»).
   Исключение: prev MOVING и implied в допуске серии (выезд из тоннеля)
   --> SUSPECT trust=10 + jump
3. Потолок скорости cap (см. 3.2): implied > cap --> SUSPECT + jump
4. Резкий разворот: implied > 8 м/с И угол > 120 градусов --> SUSPECT + jump
5. Согласная точка: trust += 15 (макс 100; при acc > 15 м потолок 60)
   prev MOVING --> MOVING (open = trust >= 30)
   иначе: implied > 0.5 --> MOVING + сброс окна при трогании (см. 3.3)
           иначе --> STAND
6. После тишины (dt > 120с, кроме SUSPECT): trust=START(40),
   MOVING --> кандидат ворот C (openFog=true), STAND --> закрыто
```

### 3.2. Потолок cap: максимум из оценок

```
cap = max(15, 2.5 * медиана_окна, 3.0 * недавний_максимум, старт_из_медленного)
старт_из_медленного = 28, если медиана < 5, иначе 0
(контекст неизвестен: история >= 3 без prev --> 3.0; иначе 15)
```

| Оценка | Работа |
|---|---|
| пол 15 м/с | абсолютный минимум |
| медиана 2.5x | ровный крейсер (устойчива к 1 выбросу) |
| рывок 3x | продолжение разгона, пока медиана догоняет |
| старт 28 м/с | запуск из ползучего/стояночного (медиана < 5) |

Границы из данных 19.09: запуски до 26.3 м/с — честные, выбросы от 31 —
подозрительные; 28 между ними (225 м за 8 с). Телепорт 500,
разворот и ворота C страхуют дальше.

### 3.3. Сброс окна при трогании

STAND-выход в MOVING с implied > 1 м/с (выше GPS-джиттера ~0.5, ниже шага):
окно чистится, последний кадр остается якорем непрерывности. Без сброса
стояночные нули держат медиану внизу еще ~8 точек (~1 км серого).
Джиттер сброс не триггерит — статика набирает свои 5 точек.

### 3.4. Состояния и доверие

```
        +------------------+
        |      STAND       | trust 40..80, openFog=false всегда
        |  (стою/холодный  |
        |   старт/возврат) |
        +--------+---------+
                 | implied > 0.5, в допуске cap
                 v
        +------------------+
        |      MOVING      | trust +15/точка до 100, открывается с 30,
        |                  | полная кисть с 70; openFog=false только
        +--------+---------+ до решения ворот C больше не бывает
                 | implied > cap / разворот / телепорт
                 v
        +------------------+
        |     SUSPECT      | trust=10, openFog=false навсегда,
        |                  | countReject=jump, возврат --> STAND
        +------------------+
```

Цвета истории: синий trust >= 30, серый пунктир ниже (фактически SUSPECT).

## 4. PendingGate (ворота C: решение с будущим)

Последние LAG=2 точки всегда ждут successors. Разбирается все старше:
возврат (отход > 200м, возврат ближе половины) --> `veto_return`,
протухание (> 600с) --> `veto_stale`, иначе подтвердить. Причина вето пишется
в `rejectReason` точки (аудит, счетчики не трогает). Подтвержденные открывают
кисть (пешком 15м / город 60м / трасса 100м; при trust < 70 или acc > 15м —
минимум) + коридоры между соседними (разрыв > 500м — только круги по концам).

## 5. Калибровочная история 19.09 (что было сломано)

Симптом: серые пунктирные километры посреди синей линии + закрытый туман.
Разбор выгрузки (1134 точки): 25 серых серий, все — старт/разгон с места при
чистом GPS; телепортов 0, разворотов 0, accuracy в сериях 4–10 м.

```
Было: cap = STAND 3.0 / медиана 2.5x --> старт 5-6 м/с = ложный SUSPECT (53),
      медиана травилась стояночными нулями еще ~8 точек,
      первая точка после тишины ветировалась навсегда.
Стало (replay тем же треком): SUSPECT 53 -> 2, серых 6154 м -> 248 м,
      дистанция 35.1 -> 44.4 км (серые км вернулись в километраж).
```

Остаток: 2 одиночных срабатывания разворота на выездах со дворов (8–10 м/с,
крутой поворот) — осознанно оставлено, порог разворота не трогаем без данных.

## 6. Известные ограничения (не чинить без данных)

- Мгновенный переход шаг->трасса (0.5–3 м/с полка, затем 16+ за один шаг):
  медиана не успевает, 1–2 точки могут поседеть. Самозаживление.
- Вето `veto_return` на честных поездках туда-обратно: ворота видят только
  геометрию, не намерение. Аудит есть, смягчения нет.
- Хвост дня: последние 2 точки трека висят в ожидании без будущего (как живой
  трекинг, паритет).
- Фильтр accuracy 25 м в застройке и speed-глюки чипа дают дыры в ЛИНИИ
  (не серость): лечатся только железом/сетью, в скоупе нет.
- Экскурсии позиционирования (сигнал врет на километры): режутся телепортом
  от 500 м; подпороговые (< 225 м) решает gate C; удаление — ручным фиксом
  raw + rebuild (кейс 18.09: 10 строк, lon > 28.0).
