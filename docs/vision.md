# Vision: FogMap

## Что это

Мобильное приложение на Android. Карта Яндекса покрыта туманом.
Пользователь ходит по земле — туман в посещенных местах открывается навсегда.
Визуальный дневник перемещений: «где я реально был».

## Целевая механика (вся)

1. Карта с туманом.
2. Фоновый трекинг геолокации.
3. Открытие тумана по факту посещения.
4. Статистика: открытая площадь, дистанция, треки.
5. Импорт истории (Google Timeline / GPX) — чтобы не начинать с нуля.
6. Экспорт треков (GPX) — данные принадлежат пользователю.

## Чего НЕ делаем (зафиксировано, 2026-09-14)

- Никаких квестов вида «сходи туда».
- Никаких артефактов, коллекций, редкостей.
- Никакого сюжета, персонажей, гильдий, лидербордов.
- Никакой соревновательности на старте.

Причина: нужен именно трекер с туманом, а не игра.
Если геймификация когда-то появится — отдельным решением через OpenSpec change.

## Платформа и карта

- Только Android (iOS не в скоупе).
- Карта — Яндекс MapKit. Причина: качество карт и геокодера в РФ,
  русскоязычная аудитория. Google Maps / OSM — не рассматриваем на старте.

## Принципы

- Офлайн-first: туман и треки живут на телефоне, работают без сети.
- Приватность: история перемещений — чувствительные данные, по умолчанию
  ничего никуда не отправляем. Облако/синк — только осознанным решением позже.
- Не спешить с кодом: сначала доки и решения, потом реализация.
