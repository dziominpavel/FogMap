- модель хранения снапшотов прогресса (что и сколько хранить);
- политика приватности (данные покидают устройство).

## Why

Пользователи хотят соревноваться с друзьями: видеть прогресс друг друга, сравнивать, кто быстрее открыл город. Это продолжение геймификации (после `add-achievements`) и требует выхода за пределы «офлайн-first» — вводится минимальный синк раз в день.

## What Changes

- Добавляется список друзей (связи между пользователями).
- Прогресс каждого пользователя синхронизируется раз в день (не real-time).
- Экран друга показывает усечённую версию собственного прогресса: открытые регионы (км²/%) + достижения.
- Приватность: пользователь контролирует, что именно публикуется (реализация может быть позже).

## Impact

- **Данные**: новые таблицы `friends`, `user_snapshots` (или аналог) в Room.
- **Бэкенд**: минимальный API для синка (хостинг, аутентификация) — **новая инфраструктура**.
- **Нетворкинг**: WorkManager для ежедневной синхронизации.
- **UI**: экран списка друзей, экран профиля друга.
- **Приватность**: изменение политики — данные покидают устройство (осознанное решение).
- **Зависимости**: требует `region-progress` и `achievements` (данные для отображения).
- **Не затрагивает**: локальную логику тумана/трекинга/статистики.
