## Status: backlog (заведено 2026-09-26)

Идея владельца: переключатель вида карты в настройках — **карта / спутник /
гибрид** (три положения). В реализацию не берём пока что: сначала надо
проверить, как спутник ведёт себя под вуалью тумана (контраст дырок, читаемость
границ регионов, night mode), и решить, где живёт переключатель (настройки
против кнопки на самом экране карты).

Предварительные работы (до возобновления):
- ручная проверка на устройстве: `mapWindow.map.mapType = MapType.SATELLITE`
  и `MapType.HYBRID` под `FogMaskOverlay` — видны ли дырки и границы;
- решение по контрасту вуали на фотофоне (возможно, отдельный стиль вуали
  для спутника);
- решение по UX: пункт в «Настройках» (как «Границы регионов») или кнопка
  на экране карты.

## Why

Спутник полезен там, где схематичной карты мало: лес, поля, тропы, дачи —
то есть ровно там, где владелец гуляет и открывает туман. Сейчас вид карты
фиксирован (схема Яндекса), поменять его негде. Гибрид (спутник + подписи)
— промежуточное положение для навигации по названиям улиц.

## What Changes

- Новое настройка «Вид карты»: `схема` (default) / `спутник` / `гибрид`.
- Значение сохраняется в DataStore (`PrefsKeys`) и применяется к `MapView`
  при создании и при смене — без перезапуска экрана.
- Туман, курсор, границы регионов и остальные слои остаются как есть; при
  необходимости — корректировка вуали под фотофон.

## Impact

- **MapKit**: `Map.getMapType()` / `setMapType(MapType)` — API есть в 4.42.0
  (проверено по `javap` на `maps.mobile-4.42.0-full`): enum `MapType` =
  `NONE | MAP | SATELLITE | HYBRID | VECTOR_MAP`. Спутник тянет трафик —
  предупреждение про мобильные данные уместно.
- **Данные**: одна строка в DataStore (по образцу `REGION_BORDERS`).
- **UI**: `SettingsScreen` (segmented button, как у темы) + возможно
  кнопка на `MapScreen`; мини-карта в `HistoryScreens` тоже стоит решить.
- **Рендер**: `FogMaskOverlay`/вуаль и `RegionBordersLayer` — проверка
  читаемости на спутнике (главный риск, поэтому change в backlog).
- **Не затрагивает**: трекинг, туман-логику, статистику, БД.
