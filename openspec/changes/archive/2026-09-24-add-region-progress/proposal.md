## Why

Пользователь хочет видеть прогресс исследования конкретных территорий (городов, областей, республики) в процентных/километрических величинах — «открыто 30% Минска», «12% всей республики». Сейчас статистика показывает только абсолютную площадь без привязки к регионам.

## What Changes

- Добавляются 13 регионов Беларуси (6 областных городов, 6 областей, 1 республика) с полигонными границами из OpenStreetMap.
- При открытии ячейки тумана система определяет, внутри каких регионов она находится, и инкрементирует materialized counter для каждого региона.
- Новый экран/секция статистики показывает прогресс по каждому региону: открытая площадь (км²) и процент от общей площади.
- Процент является производной величиной: `percent = (region_cells × area_per_cell) / total_area_km2 × 100`.

## Capabilities

### New Capabilities
- `region-progress`: Прогресс открытия по регионам — определение региона для ячейки, materialized counters, отображение км² и процентов.

## Impact

- **Данные**: новый тип сущности `Region` (хардкод в Kotlin), новые ключи counters `region_<id>_cells`, возможна миграция БД для добавления таблицы регионов (или хранение в assets).
- **Логика**: расширение `FogRepository.appendPoints` — проверка point-in-polygon при открытии ячейки.
- **UI**: новый экран или секция в StatsScreen для отображения прогресса по регионам.
- **Зависимости**: GeoJSON-данные регионов из OSM (конвертация в Kotlin-структуры).
- **Не затрагивает**: существующие счетчики area/distance/time, рендер тумана, трекинг.
