## Context

См. proposal.md — Why. Текущее состояние: `FogLayer` строит один полигон вуали с дырками-кольцами MapKit (`mapObjects.clear/addPolygon`), stroke красит внешний периметр и дырки, чтение уровней ветвится по зуму (`readLevelsForMapZoom`), запросы в Room на каждый сдвиг с дебаунсом 250мс, подписки на новые клетки нет. Ограничения: MapKit Full 4.42.0, minSdk 26, офлайн-first, схема БД без изменений, сборка личная (перекрытие логотипа допустимо).

## Goals / Non-Goals

**Goals:**
- Глухая вуаль с мягким краем без рамок и просвечивания, fail-closed первым кадром.
- Ноль запросов в БД на сдвиг камеры; туман ползет сам при новых открытиях.
- Точные дырки вблизи, пятна присутствия издалека, плавный переход.
- Компас и зум-чип без конфликта с логотипом и FAB.

**Non-Goals:**
- Смена сетки хранения и подсчета площади (z21 честна как была).
- Растровые тайлы тумана и серверный рендер.
- Кнопки +/- зума и 3D-tilt.

## Decisions

- **Маска — Compose Canvas sibling поверх `AndroidView(mapView)`.** Альтернативы: оставить полигоны (не дает мягкого края и fail-closed), `MapWindow.addRasterScreenOverlay` (привязка к SDK-оверлею, меньше контроля над пером). Canvas дает полный контроль над скруглением и пером, вуаль рисуется всегда. Логотип в личной сборке MAY перекрываться.
- **Проекция — `MapWindow.worldToScreen` в UI-потоке.** Альтернатива — ручной WebMercator по камере: ломается на azimuth/tilt и размере view. SDK-метод уже учитывает камеру; `null` (точка за камерой) трактуем как отсутствие дырки. Координаты в физических px → делим на density для Canvas. `screenToWorld` не нужен.
- **Tilt лок в 0.** Все `move()` переводятся на `tilt=0`; жест наклона гасится. Упрощает проекцию до плоской с поворотом, вид всегда сверху как в играх. Azimuth остается для компаса.
- **Кэш — прелоад всех `visited_cells` в память при старте + Flow-инкременты.** Альтернатива — запросы на сдвиг (текущие задержки) и viewport+запас (догрузки на быстром пане). Память под сотни тысяч клеток — единицы МБ, сдвиг режется в памяти синхронно.
- **Дырки — merged rects из `FogRects.merge` со скруглением и пером.** Альтернативы: капсулы по треку (нужны точки для показа, рост данных), круги по клеткам (объектов больше). Rect reuse-ят существующую склейку, перо 12–16px и скругление прячут сетку.
- **Перо — градиент на границе дырки, не блюр всего экрана.** Полноэкранный блюр просаживает пан на средних устройствах; локальный градиент дешевле и дает широкое мягкое пятно.
- **Дальний зум — лестница пятен: >= 13 точно, 11–13 пятна z16, < 11 пятна z14.** Альтернатива — один порог на z14 (гигантский поп рядом с точной ниткой, видно на скринах 12.9 vs 13.2) и всегда точно (перегруз). Присутствие считается из памяти проекцией потомков в родителя только для показа; данные не меняются. Дырки пересчитываются при любом движении камеры (target — ключ пересчета наряду с зумом и азимутом), иначе при пане одним пальцем карта едет под стоячим туманом.
- **Компас — рисованная стрелка Canvas в стиле Яндекс Карт.** Альтернатива — системная иконка-самолетик: не читается как компас.
- **Цвета — `FF0F1419` / `FFF6F8F7`.** Те же тона, но глухо. Полупрозрачность только в ленте пера.
- **Компас/зум — правая колонка над FAB «Где я».** Чип `15.2` read-only из `CameraListener`; компас виден при azimuth > 10°, тап анимирует `azimuth=0` на том же target/zoom. Не бьет чип записи слева и логотип справа.
- **Старый слой удалить.** `FogLayer`, ветвление уровней для показа и LRU склеек уходят; `cellsInLevel` для рендера больше не используется (остается для компакшна/статистики).

## Risks / Trade-offs

- [Risk] Перо на сотнях дырок просаживает fps → Mitigation: градиент только на границе, offscreen-кэш дырок, замер на Huawei, сужение пера при просадке.
- [Risk] `worldToScreen` возвращает null или дергается на границе → Mitigation: null = нет дырки (fail-closed), кламп к viewport.
- [Risk] Память растет с годами треков → Mitigation: HashSet клеток компактен; при миллионах — пагинация по регионам позже, схема БД та же.
- [Risk] Пятна z14 врут на метры издалека → Mitigation: принято как показ-легенда, данные честны; вблизи сужается к правде.
- [Risk] Перекрытие логотипа нарушает оферту при публикации → Mitigation: только личные сборки; перед публикацией вернуть окно под логотип отдельным change.
- [Risk] Ночная карта + глухая вуаль слишком контрастны → Mitigation: sync темы оставлен, тона те же; при жалобе — тюнинг пера, не прозрачности.

## Migration Plan

- Схема БД без миграций; код: новый пакет маски + кэш, удаление `FogLayer`, tilt=0 во всех `move()`, UI чипа/компаса.
- Откат: revert change, полигоны не восстанавливаются частично — только целиком.
