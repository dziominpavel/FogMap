## Why

Текущий туман полигонами MapKit неюзабелен: мятные рамки-лесенки по клеткам и по периметру экрана, просвечивающая вуаль, открытие пропадает при отдалении зума, при сдвиге карты на доли секунды видна реальная карта. Нужна маска в стиле RPG: глухая вуаль, мягкий край, fail-closed.

## What Changes

- Туман рисуется маской Canvas поверх карты вместо полигонов MapKit с дырками-кольцами; рамок и обводок больше нет.
- Вуаль глухая 100% (`FF0F1419` темная / `FFF6F8F7` светлая), просвечивание только в узкой ленте широкого мягкого пера 12–16px; минимум 2px на дырку.
- Fail-closed: вуаль первым кадром всегда, дырки только из памяти; слой подписан на новые клетки (Flow), туман ползет без трогания карты.
- Tilt зафиксирован в 0, разрешен только azimuth; проекция через `MapWindow.worldToScreen`.
- Дальний зум: зум >= 13 — точные скругленные дырки, зум < 13 — мягкие пятна присутствия z14; переход плавный без хлопка.
- На карту добавлены чип текущего зума (read-only, вид `15.2`) и кнопка компаса (видна при azimuth > 10°, тап возвращает север сверху с анимацией).
- **BREAKING**: полигонный слой `FogLayer` удаляется; тонкая мятная граница открытых ячеек убирается; чтение уровней по зуму (`readLevelsForMapZoom`) больше не определяет видимость; для личных сборок полноэкранная маска MAY перекрывать логотип/копирайты.

## Capabilities

### New Capabilities

- Нет новых capabilities; все изменения ложатся на существующие.

### Modified Capabilities

- `map-render`: глухая маска Canvas вместо полигонов, без границы, fail-closed, живое обновление, tilt=0, пятна присутствия z14 на дальнем зуме, допуск огрубления показа при честных данных.
- `app-shell`: чип зума и компас на главном экране карты (видимость, размещение, поведение тапа).

## Impact

- Затрагивает `MapScreen`, `FogLayer` (удаление), новый слой маски + прелоад клеток в память, `FogGrid`/`FogRepository` (только чтение, схема БД без изменений).
- MapKit Full 4.42.0 остается; новых тяжелых зависимостей нет.
- Площадь и статистика не меняются (сетка z21 честна, огрубление только в пикселях).
