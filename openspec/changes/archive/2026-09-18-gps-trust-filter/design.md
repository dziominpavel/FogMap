## Context

См. proposal.md (Why) и чендж `tracking-reliability` (зависимость): прыжок 250 м за 8 сек проходит нынешний `LocationFilter` (accuracy < 25, speed < 150 км/ч) и открывает 20-100 клеток. Идея владельца: доверие по последовательности с гистерезисом.

## Goals / Non-Goals

**Goals:**
- Выбросы (прыжок, туда-обратно, дрейф из статики) не открывают туман, но остаются в треке с пометкой.
- Честные серии (постоянная implied-скорость, стабильный курс, хороший accuracy) открывают туман кистью по скорости.
- Статика замораживает открытие.

**Non-Goals:**
- Смена базы сетки, пирамида, коридор вместо кругов, бюджеты рендера — следующий чендж (здесь только контракт "кисть + гейт").
- Нарезка трека на поездки — отдельный будущий чендж.
- ML/карты дорог (snap-to-road) — вне скоупа, только эвристики по последовательности.

## Decisions

- **Эвристики по последовательности, а не snap-to-road и не Kalman.** Причина — офлайн-first, ноль зависимостей, детерминизм и тестируемость; snap требует графа дорог (вес, офлайн-пакеты), Kalman сглаживает линию, но не дает ворота "открывать/нет".
- **Гистерезис: падение мгновенно, рост медленно.** Причина — цена ошибки асимметрична: один открытый квартал необратим (вайп кроме полного сброса), одна неоткрытая дорога дооткроется следующей прогулкой.
- **Раздельные ворота: трек пишется, туман — по доверию.** Причина — иначе возвращаемся к "пропавшему дню"; линия с пометками нужна и для отладки, и для будущей статистики по модам.
- **Доверие хранится в точке (`TrackPointEntity.trust`), а не вычисляется на лету при чтении.** Причина — воспроизводимость: переоткрытие тумана и статистика не меняются задним числом при смене эвристик; миграция старых точек — trust по умолчанию "доверенная" (поведение как сейчас).
- **Статика определяется кластером (N последних точек в малом радиусе + implied ~0), а не акселерометром.** Причина — ноль новых разрешений и сенсоров; акселерометр — возможное будущее усиление, не сейчас.

## Risks / Trade-offs

- [Risk] Пережмем: честный центр с плохим GPS станет недоверенным и не откроется → Mitigation: ворота только для тумана, линия остается; пороги калибруются полевым тестом (офис vs проспект vs трасса); кисть при среднем доверии не нулевая, а минимальная.
- [Risk] Недожмем: хитрый дрейф серией мелких прыжков наберет доверие → Mitigation: лимит роста доверия при плохом accuracy и виляющем курсе; фоновый потолок кисти до пирамиды.
- [Risk] Пороги implied-скорости зависят от контекста (пешком/авто) → Mitigation: контекст выводится из серии, а не из одной точки; reported speed — подсказка, не вердикт.
