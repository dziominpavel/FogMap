## Why

Офис открывает целый квартал: один прыжок GPS 200-300 м за 8 сек проходит фильтр (скорость < 150 км/ч, accuracy иногда < 25) и раскрывает круг 200-500 м (~20-100 клеток). Одновременно строгий фильтр по accuracy убивает честные поездки в центре. Нужна идея владельца: верить не одной точке, а последовательности — уровень доверия по истории (стоял, потом резко 20 км/ч, потом вернулся назад = выброс; серия с постоянной скоростью = правда).

## What Changes

- Фильтр смотрит на историю: implied-скорость (дистанция/время между соседями), скачок курса, возврат "туда-обратно", статичный кластер (стою час в куче 20 м).
- Состояния STAND / MOVING / SUSPECT с гистерезисом: доверие падает мгновенно (один прыжок), растет медленно (серия согласных точек).
- Раздельные ворота (зависит от `tracking-reliability`): сырые точки пишутся почти всегда (с пометкой доверия), туман открывается только при достаточном доверии. Пропавшего дня больше нет — есть линия с пометками.
- Кисть адаптивная: низкое доверие = минимум (1 клетка) или пауза открытия; среднее = по скорости; высокое = полная + коридор (коридор финализируется в чендже пирамиды, здесь — контракт).
- Статика замораживает открытие: стою в офисе = ничего нового не открываем, прыжки из статики недоверенные по определению.

## Capabilities

### New Capabilities

- `gps-trust`: уровень доверия точки по последовательности (сигналы implied speed / курс / возврат / статика, состояния STAND/MOVING/SUSPECT, гистерезис).

### Modified Capabilities

- `tracking`: отброс расширяется прыжками и статикой (не только accuracy/speed/mock); отброс по прыжку фиксируется в счетчике причины `jump` (счетчики введены в `tracking-reliability`).
- `fog-grid`: открытие туманом gates по доверию — недоверенные точки ячеек не открывают; кисть зависит от доверия и accuracy, а не только от скорости провайдера.

## Impact

- Затрагивает: `LocationFilter` (история + trust), `TrackingService` (контекст соседних точек), `FogRepository.appendPoints` (гейт по доверию, пометка точек), `TrackPointEntity` (поле доверия), статистика (площадь только от доверенных).
- Требует сначала `tracking-reliability` (счетчики причин, честный трек, watchdog). Не затрагивает: сетку/пирамиду, рендер, историю UI.
