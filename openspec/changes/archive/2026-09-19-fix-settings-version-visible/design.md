## Context

См. `proposal.md` (Why). Текущее состояние: `SettingsScreen.kt` строит все секции одним `Column` без прокрутки (`Modifier.padding(pad).fillMaxSize().padding(16.dp)`). Временная секция диагностики из `dev-logging` добавила высоту и вытолкнула карточку «О программе» за край. Версия (`PackageManager.versionName`) и `BuildConfig.BUILD_TIME` в коде есть, отображение не удалено. Ограничения: только portrait, только русский, временную диагностику не трогаем содержательно, BottomBar сохраняется.

## Goals / Non-Goals

**Goals:**
- Любая секция настроек достижима скроллом при переполнении, включая «О программе».
- Версия и сборка всегда отображаются, пустое значение не дает пустую строку.

**Non-Goals:**
- Редизайн настроек, перенос секций, изменение порядка.
- Изменение временной диагностики (`dev-logging`) и навигации.
- Скролл других экранов — только проверка, без переделок в этом чендже.

## Decisions

- **Прокрутка через `verticalScroll(rememberScrollState())` на внешнем `Column`, а не `LazyColumn`.**
  Причина: контент маленький и статичный (5 карточек), ленивая компоновка не нужна, дифф минимальный, состояние скролла сохраняется рекомпозицией. Альтернатива `LazyColumn` отклонена как избыточная для фиксированного списка.
- **Отступ снизу контента для BottomBar через `contentPadding` / `Spacer`, а не обрезка.**
  Причина: последний элемент не должен упираться в нижнюю навигацию. Альтернатива без отступа оставляет риск частичного перекрытия на низких экранах.
- **Фолбэк версии: пустое/null значение заменяется на `BuildConfig.VERSION_NAME` или строку-заглушку.**
  Причина: сейчас `.getOrNull() ?: ""` дает `FogMap ` с пустым хвостом при ошибке `PackageManager`. Альтернатива оставить `""` отклонена — симптом похож на «пропала версия», затрудняет диагностику.

## Risks / Trade-offs

- [Риск] Крупный шрифт / маленький экран все равно дает длинный скролл → Митигация: скролл всего списка, проверка на эмуляторе с увеличенным шрифтом.
- [Риск] `verticalScroll` + пересоздание `remember` версии при повороте → Митигация: поведение не меняется, portrait-only, `remember` сохраняется.
- [Трейд-офф] Минимальный дифф вместо `LazyColumn` → при росте секций свыше ~10 придется пересмотреть, но сейчас диагностика временная.
