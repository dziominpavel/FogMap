## MODIFIED Requirements

### Requirement: Рендер только видимой области
Система SHALL держать открытые клетки в памяти (прелоад при старте + Flow-инкременты) и резать viewport в памяти без запросов в БД на сдвиг камеры; склейка соседних ячеек в прямоугольники сохраняется для дырок. На зуме >= 13 система SHALL рисовать точные скругленные дырки, на зуме 11–13 — мягкие пятна присутствия, ниже 11 — пятна z14, с плавным переходом без хлопающего попа. Пятна присутствия на среднем зуме SHALL выбираться лесенкой: сначала z18 (~90 м), при переборе бюджета отрисовки — z16; ниже 11 — пятна z14. Переключение точных дырок на пятна SHALL иметь гистерезис: возврат к точным дыркам происходит только когда число точных дырок опускается ниже порога возврата, строго меньшего лимита перебора. Грубые пятна присутствия SHALL рисоваться с увеличенным скруглением и пером относительно размера дырки в пикселях, без острых углов сетки. Дырки SHALL пересчитываться при любом движении камеры (пан, зум): туман привязан к карте и едет вместе с ней. Вуаль SHALL рисоваться первым кадром всегда (fail-closed): дырки появляются только при доказанности из памяти. При превышении бюджета точных дырок система SHALL откатываться на мягкие пятна присутствия вместо глухой вуали. Глухая вуаль при переборе SHALL применяться только когда и пятна присутствия превышают бюджет отрисовки.

#### Scenario: Пан и зум без просвечивания
- **WHEN** пользователь двигает карту или меняет зум
- **THEN** вуаль стоит непрерывно, дырки едут синхронно из памяти, голая карта не вспыхивает

#### Scenario: Город целиком не тормозит
- **WHEN** пользователь отдаляется на весь город с сотнями тысяч открытых мелких ячеек
- **THEN** слой показывает мягкие пятна z16/z14 без лагов; глухая вуаль — только если и пятна превышают лимит

#### Scenario: Туман догоняет без трогания карты
- **WHEN** пользователь идет с неподвижной картой и открываются новые клетки
- **THEN** дырки ползут сами по Flow-обновлению без сдвига камеры

#### Scenario: Туман едет вместе с картой
- **WHEN** пользователь двигает карту одним пальцем без смены зума
- **THEN** дырки смещаются синхронно с картой, отставания вуали нет

#### Scenario: Перебор точных дырок дает пятна, а не черный экран
- **WHEN** пользователь на зуме >= 13 во вьюпорте с числом точных дырок выше лимита (окно примерно 13–13,6 в городе)
- **THEN** слой показывает мягкие пятна присутствия вместо глухой вуали, открытый туман не пропадает

#### Scenario: Пан на границе бюджета не хлопает
- **WHEN** пользователь на зуме 13–14 слегка сдвигает карту и число точных дырок колеблется вокруг лимита
- **THEN** режим показа не прыгает каждый кадр между точным и пятнами: возврат к точным происходит только ниже порога возврата

#### Scenario: Fallback сначала мелкий
- **WHEN** число точных дырок превышает лимит на зуме >= 13
- **THEN** слой показывает пятна z18, а при переборе и z18 — пятна z16; глухая вуаль — только при переборе пятен

#### Scenario: Грубые пятна без острых углов
- **WHEN** пользователь рассматривает пятна присутствия на среднем зуме
- **THEN** углы пятен скруглены, ступени сетки не читаются острыми углами
