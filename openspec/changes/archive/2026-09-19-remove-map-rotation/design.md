## Context

См. `proposal.md` (Why). Текущее состояние: `MapScreen.kt:158` гасит только `isTiltGesturesEnabled`, rotate-жест жив; `camAzimuth` — remember-состояние и ключ пересчёта дырок (`MapScreen.kt:167,287`), FAB-компас со сбросом (`:378-422`); проекция дырок — 2 угла TL+BR (`:307-322`), точна только при севере сверху; `DevCameraStats.onEvent` принимает `azimuth`, тест шторма гоняет фазу с `azimuth 68`. Проверено по стабам `maps.mobile-4.42.0-full`: `Map.setRotateGesturesEnabled(boolean)` существует (тот же интерфейс, что tilt-флаг).

## Goals / Non-Goals

**Goals:**
- Север всегда сверху с первого кадра без анимаций и без `move()` из слушателя.
- Мёртвый azimuth-тракт удалён: UI, состояние, ключи пересчёта, поле диагностики.

**Non-Goals:**
- Чинить проекцию повёрнутых дырок (4 угла / полигоны) — не нужно после лока.
- Трогать zoom-жест, пан, «Где я», чип зума, историю (`HistoryScreens` уже с `0f, 0f`).

## Decisions

- **Запрет в SDK одной строкой** `map.isRotateGesturesEnabled = false` рядом с tilt-локом при создании `MapView`. Альтернатива «только не крутить программно» отвергнута: жест пользователя всё равно поворачивал бы.
- **Тихое задание севера при создании** (как Москва/`tilt=0`), без анимации сброса при `ON_START` и без `move()` в `CameraListener`. Альтернатива «анимированный сброс при старте» отвергнута: лишний `move()`, риск дёрга и повторения tilt-петли.
- **Полное удаление компаса и состояния** (FAB, `showCompass`/`northOff`, `rotate`-импорт, `compass_reset`, `camAzimuth`, ключ `remember`), в `onEvent` — константа на переходный период, затем удаление поля. Альтернатива «скрыть UI, оставить код» отвергнута: оставляет шторм пересчётов и баг-класс.
- **Поля `azimuth` и `tilt` удалить из `CAMERA/agg` и `CAMERA/storm`** с обновлением теста шторма (фазы различаются zoom/частотой). Оба угла вечные константы по построению: azimuth — после этого ченджа, tilt — все `move()` с `tilt=0`, жесты выкл, возвратов нет (проверены все 4 точки `move()`); мёртвый параметр `tiltFixed` уходит вместе с ними. Альтернатива «оставить колонки нулей как tripwire» отвергнута решением владельца: дублирует вырезанный azimuth, диагностика временная.

## Risks / Trade-offs

- [Risk] Пользователи, крутившие карту, теряют жест → Mitigation: осознанный tradedoff трекера; север сверху — стандарт fog-of-war.
- [Risk] MapKit восстановит повёрнутое состояние камеры → Mitigation: флаг SDK + север при создании; слушатель `move()` не делает, петле неоткуда взяться.
- [Risk] Чurn сигнатуры `onEvent` и теста шторма → Mitigation: поле временное (dev-logging до стабилизации), правится одним ченджем.
