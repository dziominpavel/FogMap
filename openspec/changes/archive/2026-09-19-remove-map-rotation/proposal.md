## Why

Проекция дырок тумана строится по двум углам (TL+BR) и точна только при севере сверху: при повороте на ~45° диагональ схлопывается, дырки превращаются в нитки и внутри открытой области остаются полосы вуали. Поворот для трекера тумана — лишний функционал: пользы почти нет, а есть баг-класс, шторм событий камеры и лишний UI (компас).

## What Changes

- **BREAKING**: rotate-жест карты запрещён на уровне SDK (`setRotateGesturesEnabled(false)` рядом с tilt-локом), azimuth всегда 0.
- Компас удалён целиком: FAB, порог видимости > 10°, `rotate()` стрелки, лог `compass_reset`, анимация сброса на север.
- Состояние `camAzimuth` удалено; ключ пересчёта дырок — `(cells, zoom, target)`, север задаётся тихо при создании `MapView`, `move()` из слушателя камеры запрещены.
- Поле `azimuth` удалено из диагностики `CAMERA` (`agg`/`storm`), сигнатура `DevCameraStats.onEvent` и тест шторма обновлены.
- Поля `tilt`/`tilt_nonzero`/`tilt_fix` и параметр `tiltFixed` удалены из диагностики `CAMERA`: tilt вечный 0 по построению (все `move()` с `tilt=0`, жесты выкл, возвратов нет), колонки-нули не несут информации.
- Документация поведения: север всегда сверху с первого кадра.

## Capabilities

### New Capabilities

- Нет новых capabilities.

### Modified Capabilities

- `app-shell`: требование про компас (видимость при azimuth > 10°, тап возвращает север) удаляется; чип зума и «Где я» остаются.
- `map-render`: «разрешён только azimuth» заменяется на «azimuth всегда 0, rotate-жест отключён в SDK, слушатель не запускает `move()`».
- `dev-logging`: события `CAMERA` больше не содержат `azimuth`, `tilt`, `tilt_nonzero`, `tilt_fix` (`agg`/`storm`: zoom, частота, moves); сценарии pinch/шторма/tilt-петли без углов камеры.

## Impact

- Код: `MapScreen.kt` (флаг жеста, удаление компаса/состояния/ключей remember), `DevDiagAggregators.kt` (сигнатура и агрегаты), `DevCameraStormTest.kt` (фазы без azimuth).
- Зависимости: без новых; проверено по стабам `maps.mobile-4.42.0-full`: `Map.setRotateGesturesEnabled(boolean)` существует.
- Риск: пользователи, привыкшие крутить карту, теряют жест; для трекера принято осознанно.
