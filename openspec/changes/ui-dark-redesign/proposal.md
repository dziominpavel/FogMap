## Why

Текущий UI FogMap собран на голом `MaterialTheme` без токенов: светлая тема по умолчанию, навигация без иконок, кнопки на карте выглядят как дебаг-панель, статистика и история — голые `Text`, своей иконки приложения нет (в манифесте системная). Это мешает восприятию «игры с туманом» и ночным прогулкам: светлый UI слепит, туман не читается как игровой. Редизайн нужен сейчас, пока экранов всего шесть и дизайн-систему можно ввести с нуля без миграций БД.

## What Changes

- **BREAKING** Дефолтная тема — темная игровая (fog-dark), светлая остается опцией. Переключатель в Настройках: Темная / Светлая / Как в системе, выбор хранится локально.
- Единые токены цвета, типографики и форм Material3 для всех экранов (фон, карточки, кнопки, поля, диалоги).
- Нижняя навигация с иконками и индикатором записи трека.
- Карта: FAB-стек «Где я» + Пауза/Продолжить, статус-чип сессии, оформленные заглушки (нет Play Services / нет гео / нет ключа).
- Статистика: карточки метрик 2x2 + hero-карточка открытия, пустое состояние с CTA.
- История: карточки треков с иконкой маршрута и датой/км, единый стиль деталей, rename/delete.
- Настройки: секции Внешний вид / Данные / О программе, опасная зона сброса.
- Онбординг: степпер 1-2-3 с прогрессом и иллюстрациями.
- Игровые ассеты в одном стиле: adaptive-иконка приложения, small-icon уведомления, иллюстрации пустых состояний и онбординга (генерация вне репо, исходники в `docs/`, финал в `res/`).

## Capabilities

### New Capabilities

- Нет новых capabilities — поведение укладывается в существующие.

### Modified Capabilities

- `app-shell`: требование темы — SHALL поддерживать `theme_mode` dark/light/system с дефолтом dark, переключатель в настройках; отменяется «темной темы карты нет» для оболочки; добавляются требования к иконкам навигации, FAB-управлению картой, секциям настроек и игровому стилю.
- `map-render`: SHALL поддерживать ночной режим карты, синхронный с темой оболочки (с fallback на светлую карту, если контраст тумана плохой).

## Impact

- Код: `MainActivity` (FogMapTheme), новый `ui/theme/` (Color/Type/Shape), `BottomBar`, `MapScreen`, `StatsScreen`, `HistoryScreens`, `SettingsScreen`, `OnboardingScreen`, `SettingsRepository` + DataStore ключ `THEME_MODE`, `themes.xml` (DayNight + фон), `AndroidManifest` (иконка).
- Ресурсы: новые `mipmap-*/ic_launcher*`, `drawable-*/img_*`, `drawable-nodpi`, `mipmap-anydpi-v26/ic_launcher.xml`. Нужна нарезка из мастеров 1024px.
- Зависимости: без новых библиотек, только Material3 + MapKit `setNightModeEnabled` (спайк контраста тумана).
- Системы: бэкенда нет, офлайн-first сохраняется, миграции Room не нужны, крашлитика без изменений.
