## Purpose

Статистика перемещений: открытая площадь, дистанция, треки и время —
с разрезами день/неделя/все время. Считается материализованными счетчиками.

## ADDED Requirements

### Requirement: Метрики полным набором
Система SHALL показывать площадь (км²), дистанцию, количество треков
и время в пути с разрезами день/неделя/все время.

#### Scenario: Статистика дня
- **WHEN** пользователь открывает статистику за день
- **THEN** видит площадь, дистанцию, треки и время только за этот день

#### Scenario: Статистика за все время
- **WHEN** пользователь выбирает «все время»
- **THEN** видит суммарные значения с начала использования

### Requirement: Материализованные счетчики
Агрегаты SHALL храниться предподсчитанными и инкрементироваться при записи
точек, а не пересчитываться запросами на лету.

#### Scenario: Мгновенное открытие статистики
- **WHEN** пользователь открывает экран статистики
- **THEN** значения берутся из счетчиков без долгого пересчета
