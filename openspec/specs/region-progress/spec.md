## Purpose

Отслеживание прогресса открытия тумана по конкретным регионам (городам, областям, республике) с показом открытой площади и процента.

## Requirements

### Requirement: Регионы с полигонными границами
Система SHALL содержать 13 регионов Беларуси (6 областных городов, 6 областей, 1 республика), каждый определён полигоном из OpenStreetMap. Регионы хранятся как хардкод в Kotlin и расширяемы в будущем.

#### Scenario: Определение региона по точке
- **WHEN** координата точки проверяется на принадлежность региону
- **THEN** система определяет, находится ли точка внутри полигона региона (point-in-polygon)

#### Scenario: Точка на границе нескольких регионов
- **WHEN** координата находится в зоне пересечения полигонов (например, Минск внутри Минской области)
- **THEN** система инкрементирует counter для каждого региона, чей полигон содержит точку

### Requirement: Materialized counters регионов
Система SHALL хранить открытые ячейки по регионам в materialized counters с ключом `region_<id>_cells`. Инкремент SHALL происходить в той же транзакции, что и открытие ячеек (`FogRepository.appendPoints`).

#### Scenario: Открытие ячейки внутри региона
- **WHEN** подтверждается открытие ячейки с центром внутри полигона региона
- **THEN** counter `region_<id>_cells` увеличивается на вес ячейки (base-cell equivalents)

#### Scenario: Открытие ячейки вне регионов
- **WHEN** подтверждается открытие ячейки с центром вне всех полигонов
- **THEN** региональные counters не изменяются

### Requirement: Процент как производная величина
Система SHALL вычислять процент покрытия региона как производную: `percent = (region_cells × area_per_cell) / total_area_km2 × 100`. `total_area_km2` SHALL быть площадью полигонов региона, вычисляемой из геометрии в рантайме (сумма колец региона, не вложенных в другие кольца того же региона); захардкоженные официальные площади SHALL NOT использоваться знаменателем. `area_per_cell` SHALL быть реальной площадью базовой клетки с поправкой на широту региона (см. `fog-grid`). Абсолютная площадь (км²) вычисляется из counters, процент считается при отображении. Значения counters при этом SHALL меняться только вверх при открытии ячеек (без пересчёта исторических данных).

#### Scenario: Отображение прогресса региона
- **WHEN** пользователь открывает экран прогресса по регионам
- **THEN** для каждого региона показывается открытая площадь (км²) и процент от площади его полигонов

#### Scenario: Пустой прогресс
- **WHEN** для региона нет открытых ячеек
- **THEN** показывается 0 км² и 0%

#### Scenario: Полное открытие региона
- **WHEN** открыты все ячейки с центром внутри полигонов региона
- **THEN** процент близок к 100% (в допуске представительной широты, ~98–102%) и не систематически завышен

#### Scenario: Регион с отрезками территории
- **WHEN** у региона несколько колец, часть из которых вложена в другое кольцо
- **THEN** в знаменатель попадают только не вложенные (связные) куски территории

### Requirement: Экран прогресса по регионам
Система SHALL показывать прогресс по всем 13 регионам, сгруппированным по типу (города / области / республика). Каждый регион отображается карточкой с названием, открытой площадью и процентом.

#### Scenario: Группировка по типу
- **WHEN** пользователь открывает экран прогресса
- **THEN** регионы сгруппированы: «Города», «Области», «Республика»

#### Scenario: Сортировка по прогрессу
- **WHEN** в группе несколько регионов
- **THEN** они отсортированы по убыванию процента
